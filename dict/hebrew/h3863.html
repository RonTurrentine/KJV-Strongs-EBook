לוּא

Transliterationlûwʼ
Phoneticloo
Part of SpeechConjunction

Definition

a conditional particle; if; by implication (interj. as a wish) would that!

Strong's Definition / KJV Usage

if (haply), peradventure, I pray thee, though, I would, would God (that).

BDB / Thayer Definition

Original: לוּ לא לוּא

Transliteration: lû' lû' lû

Phonetic: loo

BDB Definition:

  1. if, oh that!, if only!
    1. if (unlikely condition)
    2. if only!, oh that!, would that!

Origin: a conditional particle

TWOT entry: 1085

Part(s) of speech: Conjunction
