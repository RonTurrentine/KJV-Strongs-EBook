נָסַךְ

Transliterationnâçak
Phoneticnaw-sak'
Part of SpeechVerb

Definition

to pour out, especially a libation, or to cast (metal); by analogy, to anoint aking

Strong's Definition / KJV Usage

cover, melt, offer, (cause to) pour (out), set (up).

BDB / Thayer Definition

Original: נסך

Transliteration: nâsak

Phonetic: naw-sak'

BDB Definition:

  1. to pour out, pour, offer, cast
    1. (Qal)
      1. to pour out
      2. to cast metal images
      3. to anoint (a king)
    2. (Niphal) to be anointed
    3. (Piel) to pour out (as a libation)
    4. (Hiphil) to pour out libations
    5. (Hophal) to be poured out
  2. to set, install
    1. (Qal) to install
    2. (Niphal) to be installed

Origin: a primitive root

TWOT entry: 1375,1377

Part(s) of speech: Verb
