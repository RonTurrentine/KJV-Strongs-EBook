רוּץ

Transliterationrûwts
Phoneticroots
Part of SpeechVerb

Definition

to run (for whatever reason, especially to rush)

Strong's Definition / KJV Usage

break down, divide speedily, footman, guard, bring hastily, (make) run (away, through), post.

BDB / Thayer Definition

Original: רוּץ

Transliteration: rûts

Phonetic: roots

BDB Definition:

  1. to run
    1. (Qal)
      1. to run
      2. runners (participle as subst)
    2. (Polel) to run swiftly, dart
    3. (Hiphil)
      1. to bring or move quickly, hurry
      2. to drive away from, cause to run away

Origin: a primitive root

TWOT entry: 2137

Part(s) of speech: Verb
