גּוֹרָל

Transliterationgôwrâl
Phoneticgo-rawl'
Part of SpeechNoun Masculine

Definition

properly, a pebble, i.e. a lot (small stones being used for that purpose); figuratively, a portion or destiny (as if determined by lot)

Strong's Definition / KJV Usage

lot.

BDB / Thayer Definition

Original: גּרל גּורל

Transliteration: gôrâl gôrâl

Phonetic: go-rawl'

BDB Definition:

  1. lot
    1. lot - pebbles used for systematically making decisions
  2. portion
    1. lot, portion (thing assigned by casting lots)
    2. recompense, retribution

Origin: from an unused root meaning to be rough (as stone)

TWOT entry: 381a
