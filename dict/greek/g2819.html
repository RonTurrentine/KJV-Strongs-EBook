κλῆρος

Transliterationklēros
Phoneticklay'-ros
Originprobably from G2806 (through the idea of using bits of wood, etc., for the purpose;

Definition

a die (for drawing chances); by implication, a portion (as if so secured); by extension, an acquisition (especially a patrimony, figuratively)

Strong's Definition / KJV Usage

heritage, inheritance, lot, part.
